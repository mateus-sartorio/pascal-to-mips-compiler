Compiler Architecture

          
The compiler building blocks.

        

        
        

          
The Front-End:

          
    
            
  1. Reads Pascal source code (a stream of characters) and injects into the scanner, which produces a stream of tokens;
    2. 
            
  2. This stream is processed by the parser, which produces the parse tree;
    3. 
            
  3. The semantic analyzer checks if the code is semantically correct and builds the symbol tables;
    4. 
            
  4. An abstract syntax tree (AST) is created by the AST builder.
    5. 
          

        


        

          
The Back-End:

          
Receives the AST and walks it to emit MIPS assembly code.

Semantic Analyzer

            
Walks the parse tree, checks if the grammar rules are met, and fills the symbol tables (global variables, local variables, procedures, functions, string literals).

            

          


          

            
Intermediate Language Generator

            
Creates the intermediate representation (Abstract Syntax Tree) that the Back-End consumes. This representation contains all the information needed the Back-End needs in a lean format.

            

              
              

            

          

        

      


      

        

          
Back-End

          
Turns the intermediate representation (AST) into code for the target machine.

        

        

          

            
Code Generator

            
Walks the AST and emits MIPS assembly target code.
